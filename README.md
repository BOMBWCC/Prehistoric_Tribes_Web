# Prehistoric Tribes · Web

把 2000 年代的 J2ME 手机游戏 **Prehistoric Tribes**（史前部落）移植到网页上，浏览器打开即可游玩。

移植的目标是**和原版完全一致**：游戏逻辑按原版程序逐条移植，并在模拟器上和原版逐帧对照验证（从开场一直到通关）。在此基础上加了简体中文。

> 本项目是非官方的爱好者移植，仅供学习与交流。游戏原作及其美术、音乐、文字等素材的版权归原权利人所有。

## 在线试玩

GitHub Pages：<https://bombwcc.github.io/Prehistoric_Tribes_Web/>

电脑（键盘或鼠标）和手机（触屏）都能玩。触屏和鼠标是临时的第一版操作方案，之后会和界面一起再优化。

## 操作（触屏 / 鼠标）

- **拖动画面**：移动视野（按格子移动）。
- **点地图**：第一下把光标移过去，在同一处再点一下 = 确认（选人、下命令、采集、点建筑都一样）。
- **左下角 ✓ / 右下角 ✗**：功能菜单 / 游戏菜单、返回、取消。
- **菜单里的选项**：点一下直接选中。建造卡片左右滑动换卡，点卡片确认，再按"点地图"的方式放置。
- **对话、剧情**：点屏幕任意处翻页。
- **画面下方的按钮**：
  - 框选：点亮后在画面上拖一个框，松手选中框里的人。
  - ◀ ▶：左右切换（浏览村民、选新族长、换建造卡片）。
  - 7、9：编组，点一下调出，按住半秒保存当前选择。
  - 地图：小地图。
  - 警告：镜头跳到最近一条警告的位置。

## 操作（键盘）

| 功能 | 按键 |
|---|---|
| 移动光标 / 菜单上下左右 | W A S D 或方向键 |
| 确认 / 选择 | 回车、空格 |
| 左软键（游戏中：建造菜单） | Q |
| 右软键（返回、取消、暂停） | Esc、Backspace |
| 小地图 | M |
| 跳到最近一条警告的位置 | 1 |
| 快捷帮助 | 0 |
| 编组：按住存当前选择，短按调出 | 7、9 |

一些原版技巧：在同一个单位上连按两次确认，选中屏幕内所有我方单位；按住确认并移动光标，可以拉框多选。

开场选语言时，最后一项是 **中文**。

## 本地运行

需要 Node.js 20+。

```bash
cd web
npm install
npm run dev
```

然后打开终端里提示的地址（默认 <http://localhost:5173>）。构建静态网页：`npm run build`，产物在 `web/dist/`。

## 目录

- `web/` —— 游戏本体（TypeScript + Canvas，没有使用游戏引擎）
  - `src/j2me/` —— 原版各个方法的逐条移植
  - `public/assets/` —— 从原版提取的素材（图片、地图、文字、音乐）
  - `scripts/verify-*.mjs` —— 各个移植方法的行为测试（`node scripts/verify-xxx.mjs`）
- `docs/translation-zh-CN.json` —— 简体中文译文，游戏直接读取这个文件
